
# Task005：通用工具契约

工具应是通用文件与数据原语，不得把完整 workflow 或隐藏答案封装成单一工具。

| 原语 | 输入 | 可观察输出 | 约束 |
|---|---|---|---|
| 文件读取 | 当前任务授权路径 | 字节或文本、读取错误 | 只读，不枚举未授权目录 |
| CSV 解析/写出 | 文本或新路径 | 字段记录或错误 | 遵循标准 CSV 转义；写出只允许独占创建 |
| 时间解析 | 一个带时区时间字符串 | 时区感知时刻或解析错误 | 不注入本地默认时区 |
| 集合处理 | 内存记录 | 分组、比较和选择结果 | 不包含订单 workflow 的隐藏规则 |
| 文件状态 | 当前任务授权路径 | 路径、存在状态和内容哈希 | 用于副作用核验 |

固定执行环境、具体工具版本和 sandbox 配置在 Pilot runtime freeze 中填写；缺失时状态为 `pending`，不得默认假定。
