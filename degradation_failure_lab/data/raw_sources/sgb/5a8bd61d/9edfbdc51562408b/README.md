# SpeechBrain

SpeechBrain is an all-in-one speech toolkit built in Python and PyTorch.

## Relevant capability for this task

- utterance-level WER computation
- edit-distance operation tables
- alignments and summary statistics

## Notes

- The full toolkit contains many pretrained and training workflows.
- For deterministic code_repo tasks, the local edit-distance utilities are a good target because they do not require downloading models.
- SpeechBrain exposes richer WER diagnostics than a plain scalar error rate.
