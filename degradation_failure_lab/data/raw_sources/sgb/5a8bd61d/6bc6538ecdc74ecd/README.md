# pypdf

pypdf is a pure-Python PDF library for splitting, merging, transforming, and extracting information from PDFs.

## Relevant capability for this task

- `PdfReader`
- `PdfWriter`
- page copying and reordering
- metadata read/write roundtrips

## Notes

- The modern package and import path is `pypdf`.
- pypdf can both read existing PDFs and write new PDF artifacts.
- Metadata keys in PDF files are written as PDF-style keys such as `/Title`.
