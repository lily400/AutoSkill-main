# 产品目录计数输出校验

在生成按 SKU 计数的结构化输出后，校验对象数量、字段完整性、计数为非负整数且 SKU 与产品目录完全一致。用于任何需要按目录逐项输出计数的批处理任务。

## Prompt

对已生成的按 SKU 计数的结构化输出执行合规校验：确认对象数量与产品目录中的 SKU 数量一致（每个 SKU 一个对象）；确认每个对象包含全部必需字段（sku_id 及四个计数字段）；确认所有计数均为 ≥ 0 的整数；确认 SKU ID 与产品目录完全一致。输出通过校验的对象列表，或列出明确的违规项清单。

## Objective

确保计数输出与产品目录一一对应且格式合规
## Applicable Signals

- 已生成按 SKU 计数的结构化输出
- 存在固定的产品目录或 SKU 清单作为对照基准
- 输出需交付给下游系统消费

## Contraindications

- 无固定目录或 SKU 清单
- 输出为自由文本而非结构化计数

## Intervention Moves

- 核对输出对象数量与目录 SKU 数量是否一致
- 逐对象检查必需字段是否齐全
- 检查所有计数是否为 ≥ 0 的整数
- 比对 SKU ID 与产品目录是否完全一致
- 汇总通过项或列出违规项清单

## Workflow Steps

- 获取产品目录中的 SKU 清单作为对照基准
- 统计输出对象数量，确认与目录 SKU 数量一致（每个 SKU 一个对象）
- 逐对象检查是否包含全部必需字段（sku_id 及四个计数字段）
- 检查所有计数字段是否为 ≥ 0 的整数
- 比对每个对象的 SKU ID 与产品目录，确认完全一致
- 输出通过校验的对象列表，或列出明确的违规项清单

## Constraints

- 对象数量必须与目录 SKU 数量一致，每个 SKU 对应一个对象
- 每个对象必须包含全部必需字段
- 所有计数必须为 ≥ 0 的整数
- SKU ID 必须与产品目录完全一致

## Cautions

- 字段缺失、计数为负或非整数、SKU 不匹配均视为违规，需明确列出而非静默修正
- 校验依赖准确的产品目录作为对照基准

## Output Contract

- 通过校验的计数对象列表，或明确的违规项清单

## Triggers

- 需要按目录 SKU 逐项输出计数
- 输出将被下游系统消费
