# 未分类技能 子技能地图

- parent: `未分类技能/总技能/SKILL.md`

## 子技能列表

1. [AFN 单 tick 合法动作执行](通用技能领域/Family技能/未分类技能/二级技能/AFN 单 tick 合法动作执行/SKILL.md)
   - 层级：二级技能
   - 类型：仿真推进
   - 适用条件：在 AFN 离散时间仿真中推进单个 tick：依据时间与更新顺序规则，对车辆执行合法动作（移动、装卸、等待等），并处理边容量、队列与冲突，产出更新后的状态快照与动作执行记录。
2. [AFN 控制器目标与优先级评估](通用技能领域/Family技能/未分类技能/二级技能/AFN 控制器目标与优先级评估/SKILL.md)
   - 层级：二级技能
   - 类型：决策评估
   - 适用条件：依据优先级、服务水平和控制器目标评估当前仿真状态或候选调度/信号方案，用于在给定状态下判断决策优劣并给出带评分与优先级判断的评估结论。
3. [AFN 状态快照结构化表示](通用技能领域/Family技能/未分类技能/一级技能/AFN 状态快照结构化表示/SKILL.md)
   - 层级：一级技能
   - 类型：状态表示
   - 适用条件：提供 AFN 仿真状态快照的统一分区与字段约定（GLOBAL/NODES/EDGES/VEHICLES/CONSIGNMENTS/INCIDENTS_ACTIVE），用于在任意 tick 生成或解析可复用的状态表示。当需要定义或解析仿真状态快照格式、或需要跨 tick 传递一致的仿真状态时使用。
4. [CLOSE_EDGE Entry Restriction Rule](通用技能领域/Family技能/未分类技能/二级技能/CLOSE_EDGE Entry Restriction Rule/SKILL.md)
   - 层级：二级技能
   - 类型：incident_handling
   - 适用条件：Enforces that while a CLOSE_EDGE incident is active on an edge, vehicles already on the edge continue to travel normally but no new vehicles may enter. Use when routing or admitting vehicles onto an edge under an active closure.
5. [Consignment Lateness Penalty Weighting](通用技能领域/Family技能/未分类技能/微技能/Consignment Lateness Penalty Weighting/SKILL.md)
   - 层级：微技能
   - 类型：scoring
   - 适用条件：Computes lateness penalties per tick for a late consignment based on its priority tier (LOW 0.5, STANDARD 1.0, HIGH 2.0, CRITICAL 4.0). Use when tallying penalties for late consignments during objective evaluation or Network Service Score computation.
6. [Incident Effect Application During Resolution Phase](通用技能领域/Family技能/未分类技能/二级技能/Incident Effect Application During Resolution Phase/SKILL.md)
   - 层级：二级技能
   - 类型：incident_handling
   - 适用条件：Applies active incident effects to edges during the Incident Resolution Phase of each tick, honoring StartTick/EndTick windows and reverting to baseline when expired. Use when advancing simulation ticks with active or scheduled incidents.
7. [Tick 处理与快照生成流程](通用技能领域/Family技能/未分类技能/二级技能/Tick 处理与快照生成流程/SKILL.md)
   - 层级：二级技能
   - 类型：离散时间步推进
   - 适用条件：按固定阶段顺序处理一个仿真 tick（事件→移动承诺→容量与冲突→移动执行→装卸→指标），并输出该 tick 的状态快照。适用于需要推进离散时间步并记录全局与实体状态时。
8. [Tick 更新顺序执行协议](通用技能领域/Family技能/未分类技能/一级技能/Tick 更新顺序执行协议/SKILL.md)
   - 层级：一级技能
   - 类型：离散时间步仿真推进
   - 适用条件：按固定六阶段顺序处理每个仿真 tick：事故解析、移动承诺、容量与冲突检查、移动执行、装卸、指标更新。用于需要确定性地推进交通仿真时间步时。
9. [Tick 阶段顺序执行协议](通用技能领域/Family技能/未分类技能/一级技能/Tick 阶段顺序执行协议/SKILL.md)
   - 层级：一级技能
   - 类型：离散时间步仿真
   - 适用条件：按固定六阶段顺序处理每个仿真 tick（事件解析、移动承诺、容量与冲突检查、移动执行、装卸、指标更新），确保状态更新顺序一致。
10. [三段式规则响应结构](通用技能领域/Family技能/未分类技能/二级技能/三段式规则响应结构/SKILL.md)
   - 层级：二级技能
   - 类型：规则响应格式化
   - 适用条件：将任何仿真世界查询的回复组织为固定三段结构：相关规则、状态更新与推理（编号步骤加状态快照）、最终答案并引用规则编号，使规则推理可核查、逻辑一致。
11. [事件时间窗效果应用与恢复规则](通用技能领域/Family技能/未分类技能/一级技能/事件时间窗效果应用与恢复规则/SKILL.md)
   - 层级：一级技能
   - 类型：事件处理
   - 适用条件：在 Incident Resolution Phase 按 StartTick/EndTick 半开区间应用 CLOSE_EDGE 或 REDUCE_CAPACITY 效果，并在事件结束后恢复边基线属性；用于处理带时间窗的道路事件对边容量或通行状态的影响。
12. [事件生命周期与容量影响应用](通用技能领域/Family技能/未分类技能/微技能/事件生命周期与容量影响应用/SKILL.md)
   - 层级：微技能
   - 类型：事件处理
   - 适用条件：在每 tick 的事件解析阶段，依据 StartTick/EndTick 判断事件是否生效，并对受影响边应用 CLOSE_EDGE 或 REDUCE_CAPACITY 效果；事件结束后恢复基线属性。用于需要判断某 tick 是否有事件生效或需要应用/撤销边容量与关闭效果时。
13. [事故容量折减计算](通用技能领域/Family技能/未分类技能/微技能/事故容量折减计算/SKILL.md)
   - 层级：微技能
   - 类型：事故影响建模
   - 适用条件：在事故生效区间内，按 CapacityMultiplier 对受影响边的基础最大车辆数做向下取整折减，得到有效 MaxVehicles，用于事故期间更新边容量约束。
14. [交付状态判定与延误tick计算规则](通用技能领域/Family技能/未分类技能/一级技能/交付状态判定与延误tick计算规则/SKILL.md)
   - 层级：一级技能
   - 类型：交付评估
   - 适用条件：用于交通仿真结果评估：判定consignment是否已在DestinationNode卸载完成交付，并按规则计算延误tick值（按时或提前为0，否则为DeliveredTime减DueTime）。
15. [仿真对象类型定义](通用技能领域/Family技能/未分类技能/一级技能/仿真对象类型定义/SKILL.md)
   - 层级：一级技能
   - 类型：数据模型定义
   - 适用条件：定义交通仿真追踪的四类主要对象（节点、边、车辆、货物/consignments）及其角色，用于搭建仿真数据模型或状态快照时明确对象类别。
16. [优先级加权迟到惩罚计算](通用技能领域/Family技能/未分类技能/一级技能/优先级加权迟到惩罚计算/SKILL.md)
   - 层级：一级技能
   - 类型：服务等级评估
   - 适用条件：按货物优先级（LOW/STANDARD/HIGH/CRITICAL）映射每 tick 迟到惩罚权重（0.5/1.0/2.0/4.0），用于计算单件或汇总的迟到惩罚值或纳入服务评分。
17. [信号交叉口到达边识别](通用技能领域/Family技能/未分类技能/微技能/信号交叉口到达边识别/SKILL.md)
   - 层级：微技能
   - 类型：信号配置
   - 适用条件：根据信号设置说明，识别被信号控制的交叉口节点及其受控到达边集合，用于确定信号化节点范围。适用于需要明确哪些到达边受信号控制时。
18. [信号交叉口相位-绿灯边映射查询](通用技能领域/Family技能/未分类技能/一级技能/信号交叉口相位-绿灯边映射查询/SKILL.md)
   - 层级：一级技能
   - 类型：信号配时查询
   - 适用条件：根据信号节点的周期长度与当前 tick 计算所处相位，并返回该相位允许通行的 GreenEdges 集合；用于仿真推进或状态快照时判定某条入边是否获得绿灯。
19. [信号交叉口绿灯放行与FIFO排队判定](通用技能领域/Family技能/未分类技能/一级技能/信号交叉口绿灯放行与FIFO排队判定/SKILL.md)
   - 层级：一级技能
   - 类型：信号交叉口放行判定
   - 适用条件：在信号化下游节点，按入边信号组的当前相位判定车辆本tick能否进入交叉口，并按到达队列的FIFO顺序确定同一入边多车的放行顺序。
20. [信号相位激活判定](通用技能领域/Family技能/未分类技能/微技能/信号相位激活判定/SKILL.md)
   - 层级：微技能
   - 类型：信号控制
   - 适用条件：根据固定信号周期（CycleLength）与有序相位列表（各相位含 Duration 与 GreenEdges），计算给定 tick t 的激活相位及其允许放行的入边集合，用于信号化节点的放行判定。
21. [信号相位通行准入校验](通用技能领域/Family技能/未分类技能/微技能/信号相位通行准入校验/SKILL.md)
   - 层级：微技能
   - 类型：车辆通行合法性判定
   - 适用条件：在离散时间步交通仿真中，依据当前激活相位的 GreenEdges 集合，判定某车辆能否从其所在边进入交叉口；用于每 tick 的车辆移动合法性检查。
22. [信号相位通行判定](通用技能领域/Family技能/未分类技能/微技能/信号相位通行判定/SKILL.md)
   - 层级：微技能
   - 类型：信号控制
   - 适用条件：根据当前 tick 与信号周期相位判断指定边是否处于绿灯，从而决定车辆能否进入下游节点；用于逐 tick 推进仿真时校验车辆进入合法性，并给出可进入的最早 tick。
23. [信号相位通行门控校验](通用技能领域/Family技能/未分类技能/微技能/信号相位通行门控校验/SKILL.md)
   - 层级：微技能
   - 类型：移动执行校验
   - 适用条件：在离散时间步交通仿真中，当车辆剩余行程时间归零并尝试进入受信号控制的节点时，依据当前 tick 对应相位的 GreenEdges 集合判定是否允许完成进入；若车辆所在边不在绿灯集合内，则推迟到达至后续 tick。
24. [到达先于离开的时序处理](通用技能领域/Family技能/未分类技能/微技能/到达先于离开的时序处理/SKILL.md)
   - 层级：微技能
   - 类型：事件时序处理
   - 适用条件：在同一 tick 内，当车辆到达节点与其它车辆尝试离开该节点同时发生时，先处理到达事件再处理离开事件，以保证每 tick 更新顺序一致。
25. [到达先于离开的节点tick更新顺序规则](通用技能领域/Family技能/未分类技能/二级技能/到达先于离开的节点tick更新顺序规则/SKILL.md)
   - 层级：二级技能
   - 类型：更新顺序约束
   - 适用条件：在节点级离散tick更新中，当同一tick既有车辆到达该节点、又有车辆尝试离开该节点时，强制先处理到达再处理离开，以保证更新顺序一致。
26. [到达先于离开的节点事件排序规则](通用技能领域/Family技能/未分类技能/一级技能/到达先于离开的节点事件排序规则/SKILL.md)
   - 层级：一级技能
   - 类型：更新顺序规则
   - 适用条件：在离散时间步交通仿真推进 tick 时，若同一节点在同一 tick 内同时存在车辆到达事件与车辆离开事件，规定先处理到达、再处理离开，以保证节点更新顺序的一致性。
27. [动作前置条件守卫](通用技能领域/Family技能/未分类技能/二级技能/动作前置条件守卫/SKILL.md)
   - 层级：二级技能
   - 类型：动作合法性校验
   - 适用条件：在生成车辆每tick动作请求时，对有条件动作（ENTER_EDGE、START_LOADING、START_UNLOADING、GO_OFFLINE、GO_ONLINE）校验其位置与状态前置条件；不满足则拒绝或修正该动作，仅保留合法动作请求。
28. [动作请求待校验约束](通用技能领域/Family技能/未分类技能/二级技能/动作请求待校验约束/SKILL.md)

29. [同相位实体规范排序规则](通用技能领域/Family技能/未分类技能/二级技能/同相位实体规范排序规则/SKILL.md)

   - 类型：确定性保障

32. [容量削减事件下的边容量与准入判定](通用技能领域/Family技能/未分类技能/微技能/容量削减事件下的边容量与准入判定/SKILL.md)

40. [离线车辆激活前置检查](通用技能领域/Family技能/未分类技能/二级技能/离线车辆激活前置检查/SKILL.md)
