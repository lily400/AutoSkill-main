# 未分类技能 子技能地图

- parent: `未分类技能/总技能/SKILL.md`

## 子技能列表

1. [SKU特征抽取与品类判定](通用技能领域/Family技能/未分类技能/微技能/SKU特征抽取与品类判定/SKILL.md)
   - 层级：微技能
   - 类型：商品描述结构化解析
   - 适用条件：从非结构化产品描述中抽取结构化SKU特征（产品类型、关键功能、材质、版型、使用场景、设计元素），并据此判定产品品类，为后续语义匹配或计数提供结构化输入。
2. [SKU竞品与情感计数更新](通用技能领域/Family技能/未分类技能/微技能/SKU竞品与情感计数更新/SKILL.md)
   - 层级：微技能
   - 类型：计数统计
   - 适用条件：对单个已通过校验的SKU，依据其competitor_or_nike归属与情感极性，将对应的竞品/情感组合计数器加一；用于多SKU循环统计中的原子计数步骤。
3. [SKU级适用性计数流程](通用技能领域/Family技能/未分类技能/二级技能/SKU级适用性计数流程/SKILL.md)
   - 层级：二级技能
   - 类型：计数统计
   - 适用条件：在目录与已处理评论均通过输入校验后，按SKU粒度统计适用性计数并产出可交付结果表；适用于需要按SKU输出计数交付物的场景。
4. [SKU计数逻辑一致性校验](通用技能领域/Family技能/未分类技能/二级技能/SKU计数逻辑一致性校验/SKILL.md)
   - 层级：二级技能
   - 类型：结果质量校验
   - 适用条件：对按SKU聚合的评论计数结果执行逻辑一致性检查，识别总量异常、同类别SKU计数分布失衡或全零计数等疑似语义匹配错误；用于计数结果产出后的质量把关阶段。
5. [不完整数据假设标注与继续执行](通用技能领域/Family技能/未分类技能/微技能/不完整数据假设标注与继续执行/SKILL.md)
   - 层级：微技能
   - 类型：降级执行与假设标注
   - 适用条件：当数据集不完美但存在交付时限时，基于现有数据继续分析并显式标注假设与局限，而非静默外推或阻塞。适用于需要在不阻塞的情况下推进分析的场景。
6. [产品描述品类归类](通用技能领域/Family技能/未分类技能/微技能/产品描述品类归类/SKILL.md)
   - 层级：微技能
   - 类型：商品分类
   - 适用条件：根据产品描述中的关键词，将商品归入上装、下装或外套等品类，用于SKU匹配前的品类判定。
7. [产品目录JSON校验](通用技能领域/Family技能/未分类技能/二级技能/产品目录JSON校验/SKILL.md)
   - 层级：二级技能
   - 类型：数据校验
   - 适用条件：对下游代理返回的产品目录JSON执行结构化校验，检查格式、数组结构、SKU数量、必填字段、重复ID、枚举值与文本非空，并在无效时向编排器报告。用于收到代理返回的产品目录JSON、需要确认SKU数量与字段完整性时。
8. [产品目录JSON结构校验](通用技能领域/Family技能/未分类技能/二级技能/产品目录JSON结构校验/SKILL.md)
   - 层级：二级技能
   - 类型：输入数据校验
   - 适用条件：对产品目录JSON数组执行结构与字段校验，确认每个对象含唯一sku_id、合法category枚举与非空silhouette_description；用于接收或清洗产品目录输入、进入后续匹配流程之前。
9. [产品目录分类映射校验](通用技能领域/Family技能/未分类技能/一级技能/产品目录分类映射校验/SKILL.md)
   - 层级：一级技能
   - 类型：产品分类映射
   - 适用条件：依据受约束的类别词表（tops/bottoms/outerwear）及其定义，将产品描述映射到合法类别，并校验目录中 category 字段取值是否合法。用于需要统一产品分类口径或校验目录类别字段时。
10. [产品目录计数输出校验](通用技能领域/Family技能/未分类技能/二级技能/产品目录计数输出校验/SKILL.md)
   - 层级：二级技能
   - 类型：结构化输出校验
   - 适用条件：在生成按 SKU 计数的结构化输出后，校验对象数量、字段完整性、计数为非负整数且 SKU 与产品目录完全一致。用于任何需要按目录逐项输出计数的批处理任务。
11. [低样本量标注继续流程](通用技能领域/Family技能/未分类技能/二级技能/低样本量标注继续流程/SKILL.md)
   - 层级：二级技能
   - 类型：样本量异常处理
   - 适用条件：当筛选后 Nike 或竞品评论少于 10 条时，在状态说明中标注低样本量条件并继续推进分析，而不是中止流程。适用于输入结构已通过校验、但筛选后样本量不足的场景。
12. [保守语义匹配阈值判定](通用技能领域/Family技能/未分类技能/微技能/保守语义匹配阈值判定/SKILL.md)
   - 层级：微技能
   - 类型：语义匹配
   - 适用条件：在评论与产品SKU的语义适用性判定阶段，评估语义关联强度，仅在关联明确且强时判定为适用，弱关联或不清时判定为不适用，以抑制过度计数。
13. [品类硬匹配与语义相似度判定](通用技能领域/Family技能/未分类技能/二级技能/品类硬匹配与语义相似度判定/SKILL.md)
   - 层级：二级技能
   - 类型：商品语义匹配
   - 适用条件：在存在品类硬性约束的商品匹配任务中，先按品类做硬性过滤，再在候选内做语义相似度判断，输出满足品类约束的匹配结果及相似度判定。
14. [多SKU语义匹配计数](通用技能领域/Family技能/未分类技能/二级技能/多SKU语义匹配计数/SKILL.md)
   - 层级：二级技能
   - 类型：语义匹配计数
   - 适用条件：将每条评论与产品目录做语义匹配，当一条评论可匹配多个 SKU 时分别计入各 SKU，避免漏计，最终产出每 SKU 评论计数 JSON 及简要状态说明。
15. [多阶段商品策展流水线编排](通用技能领域/Family技能/未分类技能/一级技能/多阶段商品策展流水线编排/SKILL.md)
   - 层级：一级技能
   - 类型：多阶段流程编排
   - 适用条件：按顺序编排评论处理、并行市场分析、销售预测、约束优化与输出生成五个阶段，用于端到端完成商品组合策展任务；当任务需要从原始评论推进到最终策展方案、且可拆分为多个可交接阶段时使用。
16. [抽样自检与纠错复核](通用技能领域/Family技能/未分类技能/二级技能/抽样自检与纠错复核/SKILL.md)
   - 层级：二级技能
   - 类型：输出质量校验
   - 适用条件：在返回最终分析输出前，随机抽取3-5个SKU进行抽样复核，核验评审计数、类目匹配与情感分类是否准确；若发现已知错误，先修正再输出，确保交付物无已知错误。
17. [按SKU生成四类情感计数并输出JSON](通用技能领域/Family技能/未分类技能/二级技能/按SKU生成四类情感计数并输出JSON/SKILL.md)
   - 层级：二级技能
   - 类型：评论情感聚合
   - 适用条件：基于产品目录与已处理评论，为每个SKU统计四类情感计数，并输出固定长度JSON数组及含评论统计的SUCCESS状态消息。适用于已提供产品目录与评论数据、需要按SKU交付情感计数的场景。
18. [按品牌文本的 Nike/竞品二分归类](通用技能领域/Family技能/未分类技能/微技能/按品牌文本的 Nike-竞品二分归类/SKILL.md)
   - 层级：微技能
   - 类型：评论分类
   - 适用条件：当结构化品牌标志（competitor_or_nike）缺失时，依据评论文本中明确出现的品牌线索，将每条记录归为 nike 或 competitor，作为下游按 Nike/竞品拆分计数的临时充分方案。
19. [无效或不完整输入处理](通用技能领域/Family技能/未分类技能/二级技能/无效或不完整输入处理/SKILL.md)
   - 层级：二级技能
   - 类型：输入校验
   - 适用条件：在批处理前对结构化输入（如 JSON 产品目录）执行有效性校验，识别缺失字段、格式异常或目录无效的情况，并给出可追溯的降级处理动作，避免产出错误的结构化结果。
20. [无效或不完整输入处理规则](通用技能领域/Family技能/未分类技能/二级技能/无效或不完整输入处理规则/SKILL.md)
   - 层级：二级技能
   - 类型：输入校验与异常处理
   - 适用条件：当产品目录JSON校验失败或输入字段缺失、不完整时，按既定规则给出明确的处理结论或拒绝输出说明，避免臆造匹配结果，保障后续匹配流程的输入可靠性。
21. [混合情感评论极性判定规则](通用技能领域/Family技能/未分类技能/微技能/混合情感评论极性判定规则/SKILL.md)
   - 层级：微技能
   - 类型：情感分类
   - 适用条件：对同时包含正面与负面内容的评论，按主导情感判定单一极性；均衡时默认判为负面以保守避免误判。用于情感分类计数前的极性裁决。
22. [目录与清单差异核验](通用技能领域/Family技能/未分类技能/二级技能/目录与清单差异核验/SKILL.md)
   - 层级：二级技能
   - 类型：数据一致性校验
   - 适用条件：当产品目录导出与规划清单的SKU总数或分类计数不一致时，先核对导出日志与去重说明，确认权威数据源与最终SKU基数，再允许下游计数计算。
23. [目录缺口不臆测的完整性守则](通用技能领域/Family技能/未分类技能/二级技能/目录缺口不臆测的完整性守则/SKILL.md)
   - 层级：二级技能
   - 类型：数据完整性治理
   - 适用条件：当产品目录的SKU数量与既定口径不一致或存在缺口时，不按假设补齐或臆测缺失项，先标记缺口并升级确认，再决定是否继续分析。
24. [类别匹配硬性校验](通用技能领域/Family技能/未分类技能/微技能/类别匹配硬性校验/SKILL.md)
   - 层级：微技能
   - 类型：评论-商品语义匹配
   - 适用条件：在语义相似度判断之前，先校验评论所指商品类别与SKU类别是否一致；类别不符即判定为不匹配，用于防止跨类别误配。
25. [类别匹配硬约束判定](通用技能领域/Family技能/未分类技能/微技能/类别匹配硬约束判定/SKILL.md)
   - 层级：微技能
   - 类型：类别分类
   - 适用条件：依据预定义封闭类别清单对条目做硬性类别归属判定，确保每个条目只被赋予清单内的合法类别标签，不得自造类别；无法归类的条目明确标记为无法归类。
26. [约束优化选品](通用技能领域/Family技能/未分类技能/二级技能/约束优化选品/SKILL.md)
   - 层级：二级技能
   - 类型：选品优化
   - 适用条件：在已有需求预测与市场情报输入、且存在明确业务约束规则的条件下，执行基于约束的SKU选择，产出满足硬性规则并最大化收入的SKU组合方案。用于商品策展流程中的优化阶段。
27. [缺失SKU占位假设拒绝规则](通用技能领域/Family技能/未分类技能/二级技能/缺失SKU占位假设拒绝规则/SKILL.md)
   - 层级：二级技能
   - 类型：数据完整性合规
   - 适用条件：当上游为赶进度要求用占位假设（如将缺失SKU视为某类产品）填补缺失数据时，拒绝该假设，坚持基于实际目录数据计算或明确标注数据缺口。
28. [缺失分类字段的数据质量校验与退回](通用技能领域/Family技能/未分类技能/二级技能/缺失分类字段的数据质量校验与退回/SKILL.md)
   - 层级：二级技能
   - 类型：数据质量管控
   - 适用条件：当处理后的评论数据缺少必需分类字段（如 brand、competitor_or_nike）时，阻断后续处理并要求源系统提供修正输入，禁止从无关字段推断分类值。用于数据预处理阶段的数据质量守门。
29. [规范类别桶映射校验](通用技能领域/Family技能/未分类技能/二级技能/规范类别桶映射校验/SKILL.md)
   - 层级：二级技能
   - 类型：数据规范校验
   - 适用条件：校验类别字段是否严格落在规定的三个规范桶内；发现越界标签时要求修正源数据，而不是事后静默重映射。适用于分类数据进入统计前的质量把关。
30. [评审到SKU适用性分析流程](通用技能领域/Family技能/未分类技能/二级技能/评审到SKU适用性分析流程/SKILL.md)
   - 层级：二级技能
   - 类型：评审-SKU映射与计数
   - 适用条件：对产品目录与评审数据执行校验、类别匹配与语义相似度映射、情感分类和按SKU计数，产出每SKU计数JSON与简洁状态消息，并标注假设与阻塞项。
31. [评论-商品类目匹配校验](通用技能领域/Family技能/未分类技能/二级技能/评论-商品类目匹配校验/SKILL.md)
   - 层级：二级技能
   - 类型：评论-SKU语义匹配
   - 适用条件：在将评论匹配到SKU前，先判定评论讨论的服装类目，并强制要求评论类目与SKU的category字段一致，否则不得匹配。用于判断某条评论是否适用于某SKU、且评论或SKU涉及服装类目归属的场景。
32. [评论与SKU品类匹配筛选](通用技能领域/Family技能/未分类技能/微技能/评论与SKU品类匹配筛选/SKILL.md)
   - 层级：微技能
   - 类型：评论适用性筛选
   - 适用条件：在进入属性语义分析之前，判断一条评论所讨论的产品类型是否与目标SKU的品类一致；若不一致，则判定该评论不适用于该SKU并停止后续分析。
33. [评论与SKU语义匹配判定](通用技能领域/Family技能/未分类技能/二级技能/评论与SKU语义匹配判定/SKILL.md)
   - 层级：二级技能
   - 类型：语义匹配
   - 适用条件：依据类别匹配、语义相似度、材料等价与语境一致性，判断一条评论是否适用于某SKU，并保持保守计数。用于将非结构化评论映射到产品目录条目。
34. [评论与SKU语义匹配判定](通用技能领域/Family技能/未分类技能/微技能/评论与SKU语义匹配判定-2/SKILL.md)
   - 层级：微技能
   - 类型：语义匹配
   - 适用条件：判断单条用户评论与单个产品SKU描述之间是否存在概念性语义匹配（语义等价或相关），从而决定该评论是否适用于该SKU。用于将评论映射到产品目录条目时的匹配判定环节。
35. [评论与SKU语义匹配及情感量化流程](通用技能领域/Family技能/未分类技能/二级技能/评论与SKU语义匹配及情感量化流程/SKILL.md)
   - 层级：二级技能
   - 类型：评论-商品语义匹配
   - 适用条件：对消费者评论与SKU描述执行类别匹配、语义相似度判断和情感分类，输出可逐条汇总的匹配与情感结果。适用于需要将非结构化评论映射到具体商品并量化消费者态度的场景。
36. [评论与SKU适用性判定](通用技能领域/Family技能/未分类技能/微技能/评论与SKU适用性判定/SKILL.md)
   - 层级：微技能
   - 类型：评论-SKU匹配
   - 适用条件：判断单条评论是否适用于某个SKU：先核对评论讨论的产品类别与SKU类别是否一致，再判断评论中提到的属性是否与SKU的silhouette_description语义匹配；两个条件同时满足才判定为适用。用于将评论匹配到具体SKU的场景。
37. [评论分类CSV输出校验](通用技能领域/Family技能/未分类技能/二级技能/评论分类CSV输出校验/SKILL.md)
   - 层级：二级技能
   - 类型：数据产出校验
   - 适用条件：在评论分类结果交付给编排器或下游分析前，对CSV产出执行格式、列完整性、分类取值合法性与最小行数校验；校验通过则放行，不合格则向编排器返回明确错误说明。
38. [评论分类与筛选工作流](通用技能领域/Family技能/未分类技能/二级技能/评论分类与筛选工作流/SKILL.md)
