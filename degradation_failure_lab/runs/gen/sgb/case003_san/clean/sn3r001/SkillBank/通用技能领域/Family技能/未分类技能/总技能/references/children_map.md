# 未分类技能 子技能地图

- parent: `未分类技能/总技能/SKILL.md`

## 子技能列表

1. [主题语气与包容性措辞](通用技能领域/Family技能/未分类技能/微技能/主题语气与包容性措辞/SKILL.md)
   - 层级：微技能
   - 类型：语气适配
   - 适用条件：在讲解桌游规则时，让措辞与游戏本身的主题和角色设定保持一致，使用手册中的术语与主题语言提升代入感，同时避免冒犯性刻板印象并保持包容。适用于游戏有鲜明主题或角色设定、需要增强顾客代入感的讲解表达环节。
2. [保护目标支持与成就标记放置](通用技能领域/Family技能/未分类技能/微技能/保护目标支持与成就标记放置/SKILL.md)
   - 层级：微技能
   - 类型：保护目标行动
   - 适用条件：在回合的可选步骤中，检查动物园内与某个未支持保护目标匹配的图标数量，必要时返还保护标记补足图标，然后放置一个未使用的成就标记以支持该目标。
3. [保护目标支持操作](通用技能领域/Family技能/未分类技能/微技能/保护目标支持操作/SKILL.md)
   - 层级：微技能
   - 类型：保育目标支持
   - 适用条件：在回合中执行一次保育目标支持：统计动物园中与目标匹配的图标数，可返还保育标记使计数+1，但必须保留至少1个匹配图标，然后放置对应成就标记。用于玩家决定支持一个尚未支持的保育目标时。
4. [升级行动卡双动物顺序打出与配对保护标记结算](通用技能领域/Family技能/未分类技能/微技能/升级行动卡双动物顺序打出与配对保护标记结算/SKILL.md)
   - 层级：微技能
   - 类型：多板块打出
   - 适用条件：当玩家使用已升级的动物行动卡一次打出两个动物板块时，校验行动强度不低于两板块等级之和、确认栖息地匹配，先完整结算第一个动物再打出第二个，并在同名雌雄动物直接相邻时立即发放1个保护标记。
5. [回合末管理检查](通用技能领域/Family技能/未分类技能/微技能/回合末管理检查/SKILL.md)
   - 层级：微技能
   - 类型：回合末管理
   - 适用条件：在玩家回合行动全部完成后，按顺序执行回合末三项管理：检查板块上限、补充展示区、判定游戏是否结束。用于每回合收尾阶段。
6. [回合末行政整理](通用技能领域/Family技能/未分类技能/微技能/回合末行政整理/SKILL.md)
   - 层级：微技能
   - 类型：回合收尾整理
   - 适用条件：在玩家回合结束时依次执行手牌上限弃牌、展示区补位与补牌、终局条件检查三项固定动作，用于每个回合收尾以保持公共展示区与手牌合规。
7. [回合结束行政整理](通用技能领域/Family技能/未分类技能/微技能/回合结束行政整理/SKILL.md)
   - 层级：微技能
   - 类型：回合收尾
   - 适用条件：在回合结束时按固定顺序完成三项收尾整理：手牌上限弃牌、展示区补位与补牌、终局条件检查。用于每回合收尾的固定行政流程，确保回合交接前状态合规。
8. [困惑澄清与换法重述](通用技能领域/Family技能/未分类技能/微技能/困惑澄清与换法重述/SKILL.md)
   - 层级：微技能
   - 类型：理解澄清
   - 适用条件：当顾客对桌游规则术语或已讲内容表示困惑时，用通俗语言或类比重新解释；若仍困惑，则换一种表述方式而非重复原话。
9. [权威性与话题边界守则](通用技能领域/Family技能/未分类技能/二级技能/权威性与话题边界守则/SKILL.md)
   - 层级：二级技能
   - 类型：合规与边界
   - 适用条件：在桌游规则讲解中约束越界、误导与剧透风险：未经核实不作权威断言，顾客有异议时转介工作人员；不提供外部链接、不索取图片、拒绝非桌游话题，并对传承/战役游戏防剧透。
10. [板块放置与效果触发结算](通用技能领域/Family技能/未分类技能/微技能/板块放置与效果触发结算/SKILL.md)
   - 层级：微技能
   - 类型：板块放置结算
   - 适用条件：将动物或项目板块合法放置到动物园地图上（相邻已有板块或入口，必要时创建开放区），并按任意顺序完整结算触发的一次性效果、持续效果与放置奖励。用于玩家打出板块时的放置与效果处理。
11. [桌游规则情境化讲解](通用技能领域/Family技能/未分类技能/二级技能/桌游规则情境化讲解/SKILL.md)
   - 层级：二级技能
   - 类型：规则教学
   - 适用条件：当顾客询问某款桌游怎么玩、需要向不同受众介绍规则，或对规则术语感到困惑时，用不超过三句话铺垫游戏背景与氛围，再以贴合游戏主题与手册用语的语气完整、清晰地讲解规则，并对困惑术语给出通俗解释或类比。
12. [终局触发与最后回合结算流程](通用技能领域/Family技能/未分类技能/一级技能/终局触发与最后回合结算流程/SKILL.md)
   - 层级：一级技能
   - 类型：终局判定与结算
   - 适用条件：在每名玩家回合结束时检查三种终局条件，按触发者与触发方式分配额外回合和终局标记，然后衔接到最终计分。用于游戏进入收尾阶段、需要判定何时结束及如何结算时。
13. [终局触发与额外回合结算](通用技能领域/Family技能/未分类技能/二级技能/终局触发与额外回合结算/SKILL.md)
   - 层级：二级技能
   - 类型：终局判定与收尾
   - 适用条件：在每名玩家回合结束的行政阶段之后检查三项终局条件，按触发者与条件类型发放终局标记并安排额外回合，随后移交终局计分。用于游戏进入收尾阶段、需要判定何时结束与如何补偿其他玩家时。
14. [终局计分汇总流程](通用技能领域/Family技能/未分类技能/二级技能/终局计分汇总流程/SKILL.md)
   - 层级：二级技能
   - 类型：终局计分
   - 适用条件：在游戏结束后按固定顺序累加每位玩家的终局得分（动物园板块分、保护成就标记分、袋鼠与剩余保护标记分、终局标记分），并按平局规则判定胜者或平局。用于最终排名计算与得分构成核对。
15. [行动卡升级操作](通用技能领域/Family技能/未分类技能/微技能/行动卡升级操作/SKILL.md)
   - 层级：微技能
   - 类型：行动卡升级
   - 适用条件：在玩家满足某项升级标记条件后，将一张未升级的行动卡从I面翻到II面，并翻面作废对应的升级标记，从而永久增强该行动。用于回合行动中执行升级动作。
16. [行动卡升级条件检查与翻面](通用技能领域/Family技能/未分类技能/微技能/行动卡升级条件检查与翻面/SKILL.md)
   - 层级：微技能
   - 类型：行动卡升级
   - 适用条件：在回合内可选行动阶段，逐一核对未使用的升级标记条件（已支持保护目标、项目数、单一栖息地连通板块数、动物类别图标数），对每个已满足条件的标记，翻面一张未升级行动卡至II面并弃置该标记，以增强后续行动强度与选项。
17. [行动卡强度与滑轨结算](通用技能领域/Family技能/未分类技能/微技能/行动卡强度与滑轨结算/SKILL.md)
   - 层级：微技能
   - 类型：行动卡结算
   - 适用条件：结算一次行动卡行动：按行动卡当前强度判定可取/可放的牌，行动完成后将用过的行动卡移到最左槽、其余卡右移一格，并据此更新各行动卡的新强度。用于玩家询问行动卡强度如何计算，或完成行动后不确定卡牌如何移动。
18. [行动卡强度结算与左移更新](通用技能领域/Family技能/未分类技能/微技能/行动卡强度结算与左移更新/SKILL.md)
   - 层级：微技能
   - 类型：行动卡结算
   - 适用条件：在回合中执行一张行动卡的两个动作之一（取板块或打出板块），按当前强度校验并结算，随后将用过的行动卡移至最左槽并右移其余卡以更新强度。
19. [行动卡执行与强度位移结算](通用技能领域/Family技能/未分类技能/微技能/行动卡执行与强度位移结算/SKILL.md)
   - 层级：微技能
   - 类型：行动卡结算
   - 适用条件：在回合中执行一张行动卡（获取板块或打出板块），按当前强度判定可行性，结算触发效果，随后将用过的行动卡移至最左并右移其余卡以更新各卡强度。
20. [规则符号与放置条件澄清](通用技能领域/Family技能/未分类技能/一级技能/规则符号与放置条件澄清/SKILL.md)
   - 层级：一级技能
   - 类型：规则澄清
   - 适用条件：针对桌游中特定符号（如水域符号、板块背面符号）与放置限制（如是否必须临河、何时可倒置板块）给出简明、准确的规则解释。适用于玩家在开局前询问符号含义或放置合法性时，帮助消除规则歧义。
21. [触发效果结算顺序规则](通用技能领域/Family技能/未分类技能/一级技能/触发效果结算顺序规则/SKILL.md)
   - 层级：一级技能
   - 类型：效果结算
   - 适用条件：当放置牌同时触发多个一次性效果、持续效果或放置奖励时，说明玩家可自选结算顺序；一次行动放两张动物时须先结算完第一只的全部效果再放第二只。用于玩家询问多个效果如何先后结算。
