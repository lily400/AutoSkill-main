# qsv-select 子技能地图

- parent: `qsv-select/总技能/SKILL.md`

## 子技能列表

1. [CSV 列选择与重排](通用技能领域/Family技能/qsv-select/二级技能/CSV 列选择与重排/SKILL.md)
   - 层级：二级技能
   - 类型：列选择
   - 适用条件：使用 qsv select 的列选择器语法，按索引、名称、范围或正则选择、重排、反转、复制或删除 CSV 列，生成仅包含目标列集合与顺序的 CSV 输出。适用于需要精确控制输出列集合与顺序的场景。
2. [敏感列排除](通用技能领域/Family技能/qsv-select/二级技能/敏感列排除/SKILL.md)
   - 层级：二级技能
   - 类型：数据脱敏
   - 适用条件：使用 qsv select 的否定正则选择器在输出中排除匹配敏感模式的列（如 SSN、account_no、password），适用于数据脱敏或共享前的列裁剪。
