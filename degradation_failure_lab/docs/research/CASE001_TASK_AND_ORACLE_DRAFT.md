## 1. 目标规则与选取理由

优先保留 R1，不换成更复杂的正则/随机/引用规则。原文 [select.md](D:/AS/AutoSkill-main/degradation_failure_lab/data/raw_sources/qsv/257ae7b38738688138dc430c2ccb4eef8766f3fc/select.md) L27–36 明确区分：

- R1a：`1,4` 枚举第1和第4列，不包含中间第2、第3列。
- R1b：`1-4` 连续选择第1至第4列。

目标机制可称为“枚举与闭区间的分隔符语义区分”，但不能掩盖两个原子行为。**以下 T1、T2 共同依赖 R1a；只有 T2 额外依赖 R1b。** 因而要证明同一错误跨任务传播，首选对R1a的局部干预；不能拿T1失败与T2的R1b分支失败就宣称同一原子规则传播。

现有 CORE 在 Example 1 明确保留R1a；R1b只有范围示例，解释不完整。它适合做可判分的小试点，却不是一个已经观察到R1明确错误的案例。未来退化可能不产生错误，这是有效结果，不应强造“发现”。

R3a `_` 末列作为非依赖对照：原文L63–66、CORE前言明确保留。R2重复名、R4正则、R5随机、R6引用、R7I/O选项引入更多边界或现有缺口，不作为第一轮核心依赖。

## 2. 实验任务政策（预注册建议）

三任务统一使用qsv select，真实执行其stdout产生的CSV；使用位置选择器，不得以列名/正则替代、手写答案CSV或另用通用语言重建输出。限制是为了隔离位置选择器规则，不是声称真实用户必须这样做；**结论只推广到这一受控任务政策**。不限制Agent必须逐字给出参考命令；任何满足任务与政策的合法执行方案均可判成功。

输入均为ASCII、逗号分隔、普通且唯一的表头、每行等宽、无嵌入换行/引号/空字段。字段按字符串比较，不把001转成1。文件名无空格。执行器将stdout捕获到指定artifact，不要求Agent使用--output，从而不依赖R7；所有路径使用固定工作目录内文件名，禁用联网、--help、其他文档、宿主真实数据。

依赖性有两层：任务按定义需要相应操作语义；Agent是否真的读取并使用了文档/Skill而非先验知识为 UNKNOWN，需通过读取日志与局部干预研究。工具限制不构成模型内部用证据的证明。

## 3. T1：最小字段共享视图（稀疏选择）

输入草案 `sharing.csv`：

```csv
record_id,private_note,review_code,total,region,owner
001,NOTE_A,X7,12.50,NORTH,OWN_A
002,NOTE_B,X8,0.00,SOUTH,OWN_B
003,NOTE_C,X9,104.20,WEST,OWN_C
```

用户任务指令：

> 用qsv select为共享接口生成CSV视图，只保留输入的第1列和第4列，顺序保持不变。保留表头、所有记录和字段原值，不含任何其他列。必须使用位置选择器，不按列名或正则选择，不手写输出。将命令stdout提交为shared_view。

正确行为：提取位置[1,4]，不能把两端间的字段一并输出；参考调用 `qsv select 1,4 sharing.csv`。stdout预期（设计推导，尚未实跑）：

```csv
record_id,total
001,12.50
002,0.00
003,104.20
```

依赖R1a；不需要R1b或其他复合选择语义。业务要求是窄字段共享，不是首四列截取。NOTE/OWN为合成哨兵，不是实际隐私数据，也不宣称覆盖真实去敏。

判分：退出码0、artifact为合法CSV、表头和全部3条数据逐字段精确相等、恰有2列；不得含其余列。若误用`1-4`，private_note/review_code进入输出且列数4，确定失败。

## 4. T2：同一采样输入的双消费者契约（连续包 + 稀疏监控包）

输入草案 `sampling.csv`：

```csv
sample_id,temperature,pressure,vibration,battery,location,operator
S101,20.1,101.3,0.04,88,ROOM_A,OP_A
S102,19.8,100.9,0.07,76,ROOM_B,OP_B
S103,21.0,101.5,0.02,93,ROOM_C,OP_C
```

用户任务指令：

> 同一份采样CSV要交给两个接口。接口A的batch_packet需要原始第1至第4列全部字段，按原顺序；接口B的alarm_packet只需要第1列和第4列，不要中间字段。分别用qsv select生成两个stdout artifact，均保留表头、全部记录和字段原值。必须使用位置选择器，不按列名或正则选择，不手写输出；不要把两个结果合并成一份CSV。

正确行为：分别选择[1,2,3,4]和[1,4]。参考调用为 `qsv select 1-4 sampling.csv` 与 `qsv select 1,4 sampling.csv`。不是在“两个不同数字”上机械复述T1：它测试同一输入同时服务连续全字段接口与稀疏监控接口，两个结果需要同时满足不同schema，并可观察同一Agent是否混同分隔符。

预期 `batch_packet`：

```csv
sample_id,temperature,pressure,vibration
S101,20.1,101.3,0.04
S102,19.8,100.9,0.07
S103,21.0,101.5,0.02
```

预期 `alarm_packet`：

```csv
sample_id,vibration
S101,0.04
S102,0.07
S103,0.02
```

依赖：alarm_packet与T1共享R1a；batch_packet依赖R1b。两个产物各自判分，T2主任务只有两个都通过才成功；同时保留子产物二元分数，供共享R1a机制诊断使用，不能把两份产物算作两个独立Agent样本。

如果枚举被误解释为区间，T1和T2.alarm都出现中间列；如果仅区间解释错误，只有T2.batch风险升高，不能算R1a多任务传播。T2较T1多一次命令调用是难度差异；用同一T2在所有路径/条件比较，不能仅比较T1与T2绝对成功率来估计规则效应。

## 5. T3：只导出末列状态（非目标规则对照）


用户任务指令：

正确行为：用R3a的末列符号；参考调用 `qsv select _ dispatch.csv`。不需要逗号枚举或连字符区间。预期：

```csv

READY
HOLD
DONE
```

判分：退出码0、合法CSV、恰1列、表头status、3条数据及顺序精确匹配。工具日志另检查确实使用末列语义。若R1局部干预仅改变枚举/范围，此任务理应不受该规则直接影响；如果也失败，应优先检查执行器、预算、上下文或非局部改动。

## 7. 确定性 Oracle 设计（尚未实现）

使用预先人工检查、冻结的上述预期CSV作为标准，CSV解析器逐字段比较。不要用待评Agent或另一模型判分，不要从生成Skill自动推导预期，不只比较选择器字符串。Oracle只见任务ID、指定产物和执行状态，不见路径/文档条件，尽量盲判。

主判定为：任务所需命令成功退出且所有指定产物可解析、行列数量、表头、字段值和顺序完全符合预期。T2要求两个产物都通过。额外记录策略合规：允许的qsv调用、位置选择、实际执行、没有额外信息来源。可分别记录output_success与policy_compliance；主实验的task_success要求两者都通过。执行器不可用为ENVIRONMENT_BLOCKED/UNKNOWN，不应伪装成文档导致的失败。环境已确认有效后，Agent的错误命令/超时则按预注册政策判失败并保留原因。

容许LF/CRLF和合法CSV引号表示的等价差异；不容许裁剪空白、数值化、排序数据行、忽略额外列/行、删除前导零、丢表头或混入说明文字。UTF-8 BOM是否接受需在实现前明确，建议允许文件头单个BOM而保持字段内容不变。

可执行性验证必须先用已固定qsv手工/无模型执行参考命令与反例：T1误用范围必失败，T2互换两选择器至少一个产物失败，T3选非末列必失败。再对Oracle自身做错误输出、字段顺序、表头、缺行、额外列、非法CSV测试。此阶段没有做这些验证，因此不能写“Oracle已通过”或“任务已成功”。

## 9. 混杂因素与控制

| 风险 | 最小控制 |
|---|---|
| 名称/正则/先验知识绕过R1 | 位置选择政策、允许工具清单、命令日志；仍不声称能观察模型内部证据使用 |
| quoting、duplicate headers、no-headers、随机排序 | 第一轮输入主动避开，三任务不调用这些功能；不要外推到完整qsv能力 |
| T2多输出与预算差异 | 固定每个任务在两路径和三条件中的预算；所有任务统一上限并记录实际消耗；分别报告T2子产物 |
| Skill检索/证据原文泄漏 | 事前固定CORE入口，不读取references/evidence.md、原文或总导航；冻结副本记录哈希，不改变已有SKILL.md |
| 英文原文→中文Skill、长度压缩/模板残留 | 记录上下文字符/token和语言；它们属于路径处理差异，不能声称只识别冻结效应 |
| 无关退化意外改R1/R3或改变窗口布局 | 人工diff核对原子语义与结构，保留同一编辑类型/近似规模；同时保存窗口覆盖诊断 |
| 原始CSV/预期结果泄漏 | 输入只给Agent，预期只给盲Oracle；报告本身不能作为Agent额外知识源 |
| 共享冻结Skill导致样本相关 | 编译run是聚类单位；T1与T2不作为独立编译样本计算置信区间 |

该方案能定义一个可执行多任务共享规则试点，但在环境、无模型参考运行、人工原子审核与判分器测试通过之前，只是 CONDITIONAL GO。
