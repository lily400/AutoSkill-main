usage: __main__.py [-h]
                   {build,llm-extract,ingest,extract,compile,diag,retrieve-hierarchy,canonical-merge,migrate-layout}
                   ...

Run the standalone AutoSkill4Doc document pipeline.

positional arguments:
  {build,llm-extract,ingest,extract,compile,diag,retrieve-hierarchy,canonical-merge,migrate-layout}
    build               Run the full document -> skill -> registry/store
                        pipeline.
    llm-extract         Compatibility alias of `build` for the document LLM
                        extraction flow.
    ingest              Read documents and run incremental checks only.
    extract             Extract support records and skill drafts.
    compile             Compile canonical skill specs without persisting them.
    diag                Run ingest + extract in diagnostic dry-run mode.
    retrieve-hierarchy  Browse or search the visible parent/child skill
                        hierarchy.
    canonical-merge     Inspect the latest staged canonical results for one
                        bucket.
    migrate-layout      Prepare `.runtime` layout and report legacy
                        directories.

options:
  -h, --help            show this help message and exit

Examples:
  python -m AutoSkill4Doc build --file ./paper.md --dry-run
  python -m AutoSkill4Doc llm-extract --file ./cbt_docs --family-name '认知行为疗法'
  python -m AutoSkill4Doc diag --file ./paper.md --report-path ./diag.jsonl --json
  python -m AutoSkill4Doc retrieve-hierarchy --store-path SkillBank/DocSkill --profile-id psychology::认知行为疗法 --family-name '认知行为疗法'
  python -m AutoSkill4Doc canonical-merge --store-path SkillBank/DocSkill --family-name '认知行为疗法'
  python -m AutoSkill4Doc build --file ./cbt_docs --domain psychology --domain-type psychology --family-name '认知行为疗法'
  python -m AutoSkill4Doc extract --file ./docs/ --json
  autoskill4doc migrate-layout --store-path SkillBank/DocSkill --json
